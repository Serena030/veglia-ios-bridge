# 快捷指令怎么建

iOS 版本不同，按钮位置可能略有差异，但动作都一样。开始之前确认你有：

- 服务器地址：`https://你的域名/phone/activity`
- `.env` 里的 `VEGLIA_TOKEN`
- 一个你想监控的 App（先拿一个来测）
- 你想被召回到的 App 或网页

## 1. 打开 App 时上报

在「快捷指令 → 自动化 → 右上角 +」新建：

1. 选「App」，挑一个测试 App，勾「打开时」
2. 动作选「获取 URL 内容」
3. URL 填 `https://你的域名/phone/activity`
4. 方法选 `POST`，请求正文选 `JSON`
5. 加一个字段 `app`，值填 App 名（比如 `小红书`）
6. 再加一个字段 `event`，值填 `open`
7. 加请求头 `X-Auth-Token`，值是你的 token
8. 运行方式选「立即运行」，关掉「运行前询问」

先只给一个 App 建。一次勾太多出了问题不好排查。

## 2. 关闭 App 时上报

复制上面那条自动化，改两个地方：

1. 触发条件改成「关闭时」
2. `event` 的值改成 `close`

其他都不动。这里的「关闭」是切走了，不需要杀进程。

## 3. 收到邮件时召回

先建一个普通快捷指令：

1. 名字随便起，比如「Véglia Summon」
2. 如果召回到 **App**：加动作「打开 App」→ 选目标
3. 如果召回到 **网页**：加动作「打开 URL」→ 填地址
4. 手动跑一次，确认能切过去

> 网页建议先「添加到主屏幕」，召回时会像 App 一样全屏打开。

再建一条邮件自动化：

1. 选「电子邮件」
2. 发件人填你的发送邮箱（`.env` 里的 `SMTP_USER`）
3. 主题包含 `[Veglia] Summon`（和 `.env` 里的 `VEGLIA_SUMMON_SUBJECT` 一致）
4. 动作选「运行快捷指令」→ 选刚才建的那个
5. 「立即运行」，关掉「运行前询问」

## 4. 验收

打开测试 App，在服务器上看：

```bash
python3 veglia_ios.py status
```

应该能看到 `current.app` 是那个 App，`seconds` 在涨。切走以后 `current` 变成 `null`。

然后测召回：

```bash
python3 veglia_ios.py summon --reason "回来"
```

看到 `sent summon` 后等一会，手机应该会自动切过去。邮件有几十秒延迟是正常的。

## 常见问题

### 返回 `bad_token`

快捷指令里的 token 和服务器 `.env` 对不上。重新复制一遍，注意别带空格或换行。

### 状态一直在计时，关了 App 也不停

「关闭时」那条自动化没跑。检查它选的是不是同一个 App、是不是「立即运行」。

### 邮件收到了但没切 App

先手动跑一次「Véglia Summon」。手动能切，问题就在邮件自动化的发件人、主题或运行方式；手动也切不了，重新选「打开 App」的目标。

### `sent summon` 之后等了很久

SMTP 发信、邮箱推送、iOS 自动化调度，每一环都有延迟。几十秒是常态，不是实时通道。
